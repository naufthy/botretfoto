# 📸 ShutterBuddy

ShutterBuddy is an AI-powered photography mentor built with
Retrieval-Augmented Generation (RAG).

It helps users learn photography concepts using an expert-curated
photography knowledge base.

## Features

- 📚 RAG-based photography knowledge retrieval
- 🤖 Gemini-powered responses
- 🎓 Simplified Mentor Mode
- 🧑‍🏫 Detailed Instructor Mode
- 💾 Local ChromaDB vector database
- 💬 Interactive Streamlit chat interface

## Tech Stack

- Python
- Streamlit
- ChromaDB
- Google Gemini API
- Gemini Embeddings
- LangChain Text Splitters
